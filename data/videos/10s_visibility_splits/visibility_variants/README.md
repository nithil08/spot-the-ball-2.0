# Visibility Variants — 10s_visibility_splits

90 clips total: 3 visibility-split variants for each of the 30 base clips from `10s_ball_visible_no_names/`.
Each subfolder `clip_01/` through `clip_30/` holds the 3 variants for that clip.

## Variants per clip (consistent across all 30 clips)

| File | Variant | Ball Visible | Ball Hidden | Difficulty |
|------|---------|-------------|-------------|------------|
| `3s_vis_7s_hid.mov` | **Short look** | 3s | 7s | Hard — model gets only 3s to track the ball |
| `5s_vis_5s_hid.mov` | **Equal split** | 5s | 5s | Medium |
| `8s_vis_2s_hid.mov` | **Long look** | 8s | 2s | Easy — model sees the ball for most of the clip |

## Purpose
Tests whether giving the model more time watching the ball (before it disappears) improves location prediction. The 3 variants form a difficulty gradient from hard (3s) → easy (8s).
