# Visibility Variants — 5s_visibility_splits

This entire batch IS a set of visibility variants. All 5 clips are derived from `clip_1` of `5s_ball_visible_no_names/` (scenario: `academy_3_vs_1_with_keeper`, seed=23). Each clip is 5 seconds total with the ball visible for the first N seconds, then shrunk to ~5% (imperceptible) for the remaining seconds.

| `1s_vis_4s_hid.mov` | **1s visible + 4s hidden** | 1s | 4s | Hard |
| `2s_vis_3s_hid.mov` | **2s visible + 3s hidden** | 2s | 3s | Medium |

| `4s_vis_1s_hid.mov` | **4s visible + 1s hidden** | 4s | 1s | Easiest — ball visible most of the clip |

The switch point is a hard cut: ball is at full normal size before the switch, shrunk to 5% mesh scale (roughly 3–4 pixels) after.
